DiskHawkPro v1.0.0 — First public release

Overview
DiskHawkPro is a compact, dependency-free disk scanner for Windows that ships as a single executable. This release provides the core scanning features and a simple user interface for finding large files and folders quickly.

Highlights
- Single-file Windows executable — download and run (no install).
- Fast recursive disk scanning with largest-files and largest-folders views.
- File type breakdowns, duplicate finder and CSV export.

How to use
1. Download DiskHawkPro.exe from the release Assets.
2. Double-click DiskHawkPro.exe to run. No installer, no commands.
3. Pick a drive or folder to scan, browse results, or export CSV.

Download
- Attach DiskHawkPro.exe to the release Assets. Users will download that file directly.
